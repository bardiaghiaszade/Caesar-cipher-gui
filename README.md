– Encrypted Windows

### Description

This task implements a Tkinter application with two windows.
Both windows contain a text field.

Text entered in the first window is transferred to the second window.
The user can choose whether the text is transferred:
- unencrypted
- encrypted using a simple Caesar cipher

The focus of this task is on GUI interaction, not cryptographic security.

### Files

- `crypto.py`  
  Contains the Caesar cipher encryption logic.

- `crypto_gui.py`  
  Contains the Tkinter GUI code that manages both windows.

### How to run

Navigate to the task directory and run:

```bash
python crypto_gui.py
```
